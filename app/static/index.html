이상 이력

시뮬레이션 엔진이 30초마다 통계적 품질 이상을 자동 검사해서 저장한 기록입니다. 같은 설비는 5분 동안 중복 기록하지 않습니다 (지속되는 이상 하나가 매번 새 행을 만들지 않도록).

승인 큐

에이전트는 조치를 제안만 하고, 실행 여부는 사람이 결정합니다. 같은 원인의 요청은 한 건으로 합쳐 횟수만 올라가고, 오래된 요청은 자동으로 만료됩니다. 승인해도 이 화면에서 설비가 자동으로 바뀌지는 않습니다 (1단계: 사람이 직접 실행). 에이전트 제안은 컨트롤타워가 같은 설비끼리 합치고 차단/자동 기록/승인 큐로 나눕니다.

시뮬레이션 엔진

서버 안에서 1초마다 tick하며 로트를 자동 투입·진행시키고, 설비 고장/복구, 품질검사까지 스스로 수행합니다.
학습용 축소 모델입니다. 공정은 ETCH→CVD→CMP→INSPECT를 한 번만 통과하고(실제 fab은 같은 설비군을 여러 번 다시 방문하는 재진입 구조), 아래 설정값(도착 간격, 공정 시간, 고장 확률, 불량률, WIP 상한)은 공개 자료로 뒷받침되지 않는 시간 압축 데모 값입니다. 이 값으로 나온 수율·가용도·OEE·처리량은 실제 fab 성능이 아닙니다.
